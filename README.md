# DigiGrowth Brain

Dylan Groenendijk's AI agent workspace for DigiGrowth — solo AI client acquisition agency for fitness studios.

## Structure

| Folder | Description |
|---|---|
| `executive-assistant/` | Claude Code EA — calendar, email, priorities, skills |
| `lead-qualifier/` | Python agent — scrapes Google Maps, qualifies leads, exports to Sheets |

## Quick Start

**Executive Assistant** — open `executive-assistant/` in Claude Code  
**Lead Qualifier** — `cd lead-qualifier && python run.py`
