NICHE DEFINITION:
Qualified = privately owned facility where 1-on-1 or semi-private personal training is the PRIMARY service or a core revenue model. Sports performance facilities with private ownership also qualify.

Disqualified = big box gyms, franchise locations, group-only studios (yoga-only, cycling-only, Pilates-only, dance-only), or any business where personal training is an add-on rather than the focus.

AGENCY CONTEXT:
COLD CALL OPENER CRITERIA:
The one-line opener feeds into this exact cold call framework:
"Hey [Name], this is Dylan — quick question for you. I was looking at [Studio Name], and I noticed [OPENER]."

The opener must complete that sentence naturally. It should sound like something Dylan genuinely noticed — not a compliment, not a pitch.

ARTICLE RULE: Always use "a" or "an" before the program, offer, or model. NEVER use "that", "the", or "your".
  ✅ "you're running a 6-week transformation challenge"
  ❌ "you're running that 6-week transformation challenge"
  ❌ "you're running your 6-week transformation challenge"

Priority order for what to pull from the website:
1. A specific RESULT or outcome they advertise (e.g., "you're running a 6-week transformation challenge", "you're offering a 30-day money-back guarantee", "you're showing a before/after transformation program")
2. A specific OFFER or program name (e.g., "you're running a semi-private small group training model", "you're offering an unlimited membership at that price point", "you're bundling a nutrition coaching program with training")
3. A specific NICHE or client type they serve (e.g., "you're running a women's-only training program", "you're running an athlete performance program", "you're running a postpartum fitness program")
4. A specific METHOD or system (e.g., "you're using a 3-day strength training template", "you're running a hybrid in-person and virtual training setup", "you're using an assessment-first intake system")
5. If nothing specific exists — return null. Do not fabricate.
