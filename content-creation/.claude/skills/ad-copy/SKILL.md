# Ad Copy Skill

Write Facebook and Instagram ad copy for DigiGrowth's fitness studio lead generation campaigns.

---

## Trigger

Any request containing: "ad", "ad copy", "Facebook ad", "Meta ad", "paid ad", "creative"

---

## Ad Copy Framework (for every ad)

**Structure: Hook → Problem → Solution → Proof → CTA**

1. **Hook** (first line / headline) — Stop the scroll. Pattern interrupt. Speaks directly to the pain.
2. **Problem** — Agitate the pain. Make them feel it's real and costing them now.
3. **Solution** — Introduce DigiGrowth's system. Keep it simple: "We handle everything."
4. **Proof** — Specifics beat vague claims. Use numbers, timeframes, named results.
5. **CTA** — One clear action. "Click below." "Message us." "Book a free call."

---

## Mode 1: Lead Gen Ad (Primary Use Case)

**Target audience:** Fitness studio owners, gym owners, personal trainers

**Headline options (A/B test these):**
- "We Get Fitness Studios 20–40 New Clients Per Month"
- "Struggling to Fill Your Calendar? Read This."
- "Your Gym Isn't the Problem. Your Lead System Is."

**Body copy (short — 100–150 words):**
- Pain opener: "Most fitness studios are hemorrhaging potential clients..."
- Agitate: time spent, money wasted on bad ads, feast-or-famine cycle
- Solution: "We run a done-for-you acquisition system..."
- Social proof placeholder: "[X] studios use this system right now"
- CTA: "Click 'Learn More' to see how it works."

**Output:** Write primary + 2 headline variants. Label clearly.

---

## Mode 2: Retargeting Ad

**Target:** People who visited the site or engaged with content but didn't book

**Tone:** More direct, urgency-based, social proof heavy

**Framework:**
- Acknowledge they've seen DigiGrowth before
- Remove objections ("No setup fees. No long contracts.")
- Time-limited angle if applicable
- CTA: Book a call

---

## Mode 3: Video Script (Ad Hook + Body)

**Use when:** Dylan wants a video ad script

**Format:**
- 0–3 sec: Visual hook description + first spoken line
- 3–15 sec: Problem + agitation
- 15–30 sec: Solution intro
- 30–45 sec: Proof / results
- 45–60 sec: CTA
